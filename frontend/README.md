# Frontend

The React dashboard for the Azzurro review app.

- Setup, architecture and commands: see the [root README](../README.md)
- Plain-language dashboard guide: see [USER_GUIDE.md](../USER_GUIDE.md)

```bash
npm install
npm run build      # production build into dist/ (served by the backend)
npm run dev        # dev server on :5173 (proxies /api to :8000)
npm run lint
```
