# Project Instructions

You are working on a Booking.com review dashboard.

## Progress Logging

- A file named `PROGRESS.md` is the single source of truth for project progress.
- **Before starting any task**, read the top entry of `PROGRESS.md` to know what was last done.
- **After completing a meaningful step** (roughly every 30–60 minutes of work), append a new entry at the TOP of `PROGRESS.md` in this exact format:

[timestamp]
✅ Finished: <what was done>
⏭ Next: <what will be done next>
🚧 Blockers: <issues or dependencies, or "None">

- Keep the latest entry at the top.
- Be honest and specific. If you are blocked (missing API key, uncertain requirement), write that.

## Task Specifics

- Planning model: Do the plan first and log planning steps in `PROGRESS.md`.
- Implementation model: Read the plan, implement, and log coding progress.
